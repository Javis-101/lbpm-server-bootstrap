## Scientific boundary

`PRODUCTION_VALIDATED` means that server deployment, the dependency stack, LBPM build identity, GPU runtime, data contract, smoke simulation, and evidence pipeline passed engineering acceptance.

It does **not** constitute physical validation of a production water-displacing-gas simulation, residual gas saturation model, capillary-number selection, wettability model, or final multiphase parameterization.
