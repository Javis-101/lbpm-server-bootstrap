# Frozen source archives

The builder scripts populate this directory with exactly these four source archives:

- `openmpi-4.1.8.tar.gz`
- `zlib-1.3.2.tar.gz`
- `hdf5-1.14.6.tar.gz`
- `LBPM-6d686d354e5b8140841d3601e4c8c0e4e4b77e48.tar.gz`

After bundling, this directory also contains:

- `SHA256SUMS`
- `BUNDLE_MANIFEST.txt`

Do not manually modify a frozen archive after its SHA256 has been recorded.
